# Cost-Quality Pareto: Finding the Optimal Model

**Given quality scores and costs for multiple models, which one should you use? This demo computes the Pareto frontier and recommends the cheapest model that meets your quality threshold.**

Based on: [Cost and Accuracy in Multi-Agent Systems](https://arxiv.org/abs/2601.07978) (Jan 2026)

## Files

| File | Purpose |
|------|---------|
| `03-cost-quality-pareto.ipynb` | **Main demo** — Pareto frontier + model recommendations by budget |
| `requirements.txt` | Python dependencies |

## Run the Demo

Open `03-cost-quality-pareto.ipynb`. Identifies Pareto-optimal models and recommends by quality threshold.
