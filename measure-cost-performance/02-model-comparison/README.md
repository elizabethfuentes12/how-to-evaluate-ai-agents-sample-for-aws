# Model Comparison: Quality vs. Cost Across Bedrock Models

**Claude Sonnet costs 4x more than Haiku. Is it 4x better? This demo runs the same tasks on 3 Bedrock models and compares quality/cost with a Quality/$ metric.**

Based on: [KAMI: Kamiwaza Agentic Merit Index](https://arxiv.org/abs/2511.08042) (Nov 2025)

## Files

| File | Purpose |
|------|---------|
| `02-model-comparison.ipynb` | **Main demo** — 3 models, same tasks, quality vs cost table |
| `requirements.txt` | Python dependencies |

## Run the Demo

Open `02-model-comparison.ipynb`. Compares Claude Sonnet, Claude Haiku, and Amazon Nova Pro.
